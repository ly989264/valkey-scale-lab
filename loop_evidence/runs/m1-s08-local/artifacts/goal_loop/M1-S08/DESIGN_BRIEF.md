# M1-S08 Design Brief

Role: simulated design subagent
Reason: explicit subagent capacity is unavailable in this continuation; this design is kept separate from implementation and written before worker edits.

## Goal Understanding

M1-S08 turns the existing artifact report into the milestone1 deliverable shape: fully automated Chinese offline visual report with no LLM, no network/CDN/API dependency, local CSV exports, local SVG assets, complete `report_index.json`, missing metrics aggregation, cleanup results, conclusion summary, and a bottleneck answer. It should consume analysis artifacts generated by previous stages, including M1-S07 system metrics, rather than inventing report values.

## Current Code Paths

- Renderer: `src/valkey_scale_lab/report/render.py`
- Analysis input contract: `src/valkey_scale_lab/analysis/summary.py`
- Existing report tests: `tests/report/test_report_rendering.py`, `tests/report/test_system_metrics_report.py`
- Existing report quality script: `scripts/assert_report_quality.py`
- Final/report regression scripts: `scripts/assert_final_report_regression.py`, `scripts/p39_visual_report.py`
- M1-S07 report inputs: `analysis_summary.system_metrics`, `system_metrics_report_inputs`, generated CSV/SVG sections.

## Implementation Plan

- Renderer layout: write canonical outputs as `reports/index.html`, `reports/report.md`, `reports/report_index.json`, `reports/exports/*.csv`, `reports/assets/*.svg`. Preserve compatibility by optionally keeping legacy flat names or by making `report_index.json` point to canonical paths.
- Chinese coverage: change report H1/title and English section labels to Chinese; keep code field names where useful but explain them in Chinese.
- Bottleneck summary: derive a deterministic conclusion from analysis artifacts: slowest setup phase/node, slowest command, slowest management operation, highest workload p99/error, largest failover p95/split-brain window, largest RSS/system abnormal node, cleanup status, and missing metrics count.
- Offline gate: add/strengthen a script to check no external URLs (`http://`, `https://`, protocol-relative URLs), no CDN references, local SVG/CSV non-empty, required report sections present, and report index complete.
- Fixtures/tests: use M1-S07 fixture/report inputs plus report-missing/external-url failure fixtures for the gate.

## Data Propagation

- Schema/index: report index records canonical exports/assets and artifact refs.
- Reader/aggregator: use existing `analysis_summary` fields; no new measurements needed.
- Renderer: deterministic Chinese HTML/Markdown/CSV/SVG generated from analysis only.
- Gate: validates rendered files and provenance.
- Docs/artifacts: coverage matrix, worker summary, review, completion, and M1-S09 handoff.

## Coverage

- Execution shape: fake/unit/integration/smoke and real report generated from the M1-S07 bounded real artifact; heavy rungs blocked if not run.
- Scale rung: same renderer tested on success fixture plus scale 30/50/100/200 system/report-capable fixtures.
- Functional path: analysis, report, metrics, management, fault, workload, cleanup.
- Data path: artifact reader -> analysis aggregator -> renderer -> report index -> gate -> docs.
- Outcome: success, missing metrics aggregation, report input missing, external URL failure, empty asset failure.

## Review Fail Conditions

Review must fail if the report contains external dependencies, if required report outputs are missing or empty, if the conclusion is LLM/free-text not artifact-derived, if system metrics are omitted, if report values are invented, or if only a single fixture path is covered.
