# valkey-scale-lab Codex Bootstrap

This repository bootstrap package contains the phase plan, AGENTS.md, schemas, templates, and pre-authored gate scripts for building `valkey-scale-lab` with Codex App.

Start with:

```bash
python3 scripts/codex_gate.py next
```

Then follow `CODEX_START_HERE.md` and `AGENTS.md`.

The automatic loop stops after `P13_SCALE_LADDER_50_100`. `P14_SCALE_1000_OPTIN_DRYRUN` is not automatic.
