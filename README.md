# Valkey Scale Lab Repository

This repository is intentionally divided into two primary directories:

- [`project/`](project/README.md) contains the runnable package, harness,
  scripts, configuration, schemas, tests, templates, and documentation.
- `loop_evidence/` contains historical artifacts, audits, runs, and retired
  goal-loop packages.

Run project commands from `project/`. Relative compatibility links there keep
the harness artifact paths stable while evidence remains physically separate.
