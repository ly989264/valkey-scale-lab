# 03_EVIDENCE_TAXONOMY.md

Every source artifact used by acceptance must be classified. This classification is mandatory and machine-checked.

## Evidence kinds

```text
REAL_EXACT_SCALE
REAL_SMALL_SMOKE
M1_FORMAT_RECONSTRUCTED_FROM_REAL_RAW
LEGACY_EVIDENCE_ONLY
FIXTURE_ONLY
DRY_RUN_ONLY
BLOCKED_WITH_REASON
INVALID
```

## Rules

- `REAL_EXACT_SCALE`: artifact was generated by a real local Valkey run at the required scale after the relevant M1-format fields existed.
- `REAL_SMALL_SMOKE`: real local Valkey run below the exact scale, useful for runtime smoke only.
- `M1_FORMAT_RECONSTRUCTED_FROM_REAL_RAW`: acceptable only if raw real command/metric/timeline logs contain enough data to populate every M1-required field without invention.
- `LEGACY_EVIDENCE_ONLY`: old real evidence, useful for historical context, not sufficient for new M1 stage PASS.
- `FIXTURE_ONLY`: parser/schema/report test data, never sufficient for milestone acceptance.
- `DRY_RUN_ONLY`: planning-only, never sufficient for real execution claims.
- `BLOCKED_WITH_REASON`: exact-scale evidence is unavailable and must block milestone PASS.
- `INVALID`: malformed, empty, contradictory, or source path missing.

## Claim promotion rule

A claim can promote to milestone PASS only if its evidence kind is `REAL_EXACT_SCALE` or explicitly allowed `M1_FORMAT_RECONSTRUCTED_FROM_REAL_RAW` and all semantic checks pass.

Fixture, legacy, dry-run, and small-smoke evidence must not satisfy exact-scale claims.
